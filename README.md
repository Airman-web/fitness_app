# Fitness App - Flutter Chip & Wrap Demonstration

This is a small Flutter project created to demonstrate the use of the
`Wrap` and `ChoiceChip` widgets.

## Project Purpose

The project demonstrates how Flutter can be used to display fitness
workout options in a responsive layout.

## Widgets Demonstrated

### Wrap

The `Wrap` widget arranges its children horizontally and automatically
moves them to the next line when there is not enough horizontal space.

In this project, `Wrap` is used to arrange the workout options across
multiple rows.

### ChoiceChip

The `ChoiceChip` widget is used to allow the user to select one workout
option.

When a workout is selected, the selected state changes and the selected
workout is displayed below the chips.
